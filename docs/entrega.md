## Criar o repositório pela interface do GitHub

1. Entre na sua conta no [GitHub](https://github.com/).
2. Crie um repositório com um nome como `p1-compiladores`.
3. Selecione a visibilidade **Public**.
4. Envie o **conteúdo** da pasta `p1-compiladores`: o README e o notebook devem
   aparecer na raiz, junto do arquivo `p1.py` e das subpastas.
5. Registre as alterações com uma mensagem de commit, por exemplo:
   `Adiciona atividade prática de análise léxica`.
6. Confira se o README foi renderizado e se é possível abrir o notebook.
7. Abra o endereço em uma janela sem login para conferir o acesso público.

Se usar o pacote ZIP, extraia os arquivos antes. Publicar somente o ZIP não
permite ao professor navegar pelo código e ler o README na página principal.

Para enviar todos os arquivos, incluindo `.github` e `.gitignore`, também é
possível usar GitHub Desktop e escolher a pasta do projeto. A pasta `.github`
contém a verificação automática de testes; confira se foi incluída na publicação.
